Owner: Aslam

## Decision

Do not open a new project now.
Continue from the existing GitHub project with the strongest foundation.

Main continuation repository:

```text

```

Reason: this repository already represents the Universal Dragon brain and QBIT NOVA language direction. It has the clearest identity, version branch, examples, and test workflow.

## Main Rule

```text
No new project until the existing main repo has a clear roadmap, working checks, and public proof sync.
```

## Current Focus

Universal Dragon should move in this order:

1. Stabilize `Universal-Dragon-Core`.
2. Keep `qbit-nova-c` as the technical proof engine.
3. Sync public progress to `UniverseDragon14.github.io`.
4. Use `studio-site` later for practical creator tools.
5. Use `eve-app-builder` as the approval-first app creation rulebook.
