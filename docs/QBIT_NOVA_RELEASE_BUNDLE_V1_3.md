# QBIT NOVA Release Bundle v1.3

UD means Universal Dragon.

Creator: Aslam
Team: Askutty
Brain: NovaKutty
Language: QBIT NOVA
Source extension: .ud

## Purpose

QBIT NOVA v1.3 creates a portable release bundle.

The bundle can be copied separately from the full repository, installed, and run through the qbit-nova command.

## Included

- QBIT NOVA CLI
- Portable launcher
- Installer
- Native engine
- Tokenizer
- Token parser
- QVM pipeline
- NOVA runner files
- Example .ud programs
