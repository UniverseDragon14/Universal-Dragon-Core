Install Universal Dragon runtimes.

QBIT NOVA C and the earlier NOVA Termux runtime use separate repositories, commands and release tracks. Choose the runtime you actually intend to install.

QBIT NOVA C · Raspberry Pi / Debian Linux

Install QBIT NOVA C

v4.3 Tagged Release · Latest Main Runtime Verified

This installs the current GitHub main runtime from a full clone so release tags remain available to the verification chain. 

sudo apt update
sudo apt install -y git build-essential

git clone https://github.com/UniverseDragon14/qbit-nova-c.git "$HOME/qbit-nova-c"
cd "$HOME/qbit-nova-c"

bash install.sh
export PATH="$HOME/.local/bin:$PATH"
qnova-demo

Boundary: this installs a software Virtual QCPU runtime on classical hardware. It does not convert the Raspberry Pi into physical quantum hardware.

Legacy NOVA · Android Termux

Install the existing NOVA runtime

The original NOVA Termux package remains available and is not merged with QBIT NOVA C. 

pkg install curl -y
curl -L https://raw.githubusercontent.com/UniverseDragon14/Universal-Dragon-Core/nova-v1.3.5-dev/install-repo.sh | bash

pkg install nova
nova version
nova doctor

QBIT NOVA Language has no installer yet

QBIT NOVA Language is a separate experimental programming-language project. Its frozen C-implementation specification v0.1 is available through the QBIT project site, but a production compiler and runtime have not been published.
