## Purpose

This document locks the QBIT NOVA Processor Bridge concept.

## Meaning Units

### QBIT

A compact meaning unit.

A QBIT can hold a small command that expands into many internal actions.

Example:

q.safe.patch

Meaning:

check first
backup before change
validate after change
rollback on fail
learn always
reply clean

### QDOT

A small point/symbol that can hold big meaning.

QDOT is the smallest visible meaning point in QBIT NOVA.

### QSTATE

A symbolic state that can represent 0, 1, or possibility.

This is quantum-inspired, not fake quantum hardware.

### QLINK

A connector between meaning blocks.

QLINK connects:

human intent
AI interpretation
software action
hardware execution

### QPULSE

A software execution signal.

QPULSE is the force/message sent from QBIT NOVA logic into the QVM.

### QVM

QBIT NOVA Virtual Machine.

QVM converts QBIT NOVA AST/IR into executable steps for normal processors.

### QBC

QBIT Bytecode.

QBC is the compact low-load binary/byte instruction format that QVM can run.

### QBRIDGE

The bridge from QBIT NOVA meaning to processor execution.

QBRIDGE connects:

QBIT source
Tokenizer
Parser
AST
IR
QVM
QBC
CPU action

### QPU Adapter

Future adapter for real quantum hardware.

This is not active now.
It is a future connector design.
