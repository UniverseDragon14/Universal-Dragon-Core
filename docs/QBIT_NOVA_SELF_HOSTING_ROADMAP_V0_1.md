## Purpose

This document locks why bootstrap tools are used now and how QBIT NOVA will become independent later.

## Truth Lock

QBIT NOVA is the new language.

Python is only a temporary bootstrap construction tool.

Python is not the public identity of QBIT NOVA.
Python is not the final QBIT NOVA language.

## Why Bootstrap Exists

A normal computer does not understand a brand-new language at the beginning.

So the first tokenizer, parser, AST builder, IR builder, and QVM may use a host language only to teach the computer how to read QBIT NOVA.
