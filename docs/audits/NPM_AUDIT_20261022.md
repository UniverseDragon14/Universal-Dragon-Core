# Universal Dragon Core dependency audit (2026-10-22)

## Outcome

- Baseline `npm audit`: 19 vulnerabilities (3 low, 4 moderate, 11 high, 1 critical).
- Applied compatible dependency updates using `npm audit fix` and `npm update tsx`.
- Added an explicit `qs` override to `6.16.1` because Express 4's declared `~6.14.0` range otherwise retained the vulnerable transitive version.
- Final `npm audit --audit-level=low`: **0 vulnerabilities**.
- `npm run lint`: PASS (`tsc --noEmit`).
- `vite build`: PASS with Vite 6.4.5; a non-failing large-chunk (>500 kB) warning remains for separate optimization.

## Resolved dependency versions checked

- `express@4.22.1`
- `tsx@4.23.15` → `esbuild@0.28.2`
- `vite@6.4.5` → `esbuild@0.25.12`
- `qs@6.16.1` override applies to Express/body-parser transitive resolution.

The patch updates dependency lock data and records the audit evidence. It does not alter application features or force a major Express upgrade. Validation was performed in an isolated branch based on `nova-v1.4.0-dev`; no direct push to the default branch was performed.
