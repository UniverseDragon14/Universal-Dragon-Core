# QBIT NOVA Tokenizer v0.1

Creator: Aslam
Project: Universal Dragon
Brain: NovaKutty
Language: QBIT NOVA

## Purpose

This is the first QBIT NOVA tokenizer contract.

The tokenizer reads QBIT NOVA source and converts it into QBIT NOVA tokens.

Existing host tools are bootstrap tools only. They are not the public identity of QBIT NOVA.

- KEYWORD

- COLON
- SYMBOL
- NEWLINE
- INDENT
